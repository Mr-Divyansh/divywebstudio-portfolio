# 🎨 Design Philosophy

DivyWebStudio follows a simple principle:

> **Keep it modern. Keep it fast. Keep it useful.**

We avoid unnecessary complexity and focus on:

* Clear visual hierarchy
* Strong typography
* Responsive layouts
* Intuitive navigation
* Clear calls-to-action
* Fast loading
* Professional presentation
* Consistent branding

---

# 📱 Responsive Design

The website is tested across common mobile and desktop viewport sizes.

### Mobile

* 320px
* 375px
* 390px
* 414px

### Desktop

* 1366px
* 1440px

The responsive implementation focuses on:

* No unintended horizontal overflow
* Responsive typography
* Flexible layouts
* Mobile navigation drawer
* Proper image scaling
* Touch-friendly controls
* Consistent spacing

# 🔧 Running Locally

Clone the repository:

```bash
git clone https://github.com/Mr-Divyansh/divywebstudio-portfolio.git
```

Enter the project directory:

```bash
cd divywebstudio-portfolio
```

If the project is a static frontend, open:

```text
index.html
```

Alternatively, use a local development server such as VS Code Live Server.
